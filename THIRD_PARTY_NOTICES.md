# Third-party open-source references

Linkup's UI foundation adapts patterns and selected implementation ideas from these permissively licensed projects:

- Tabi — https://github.com/atharvdange618/Tabi — MIT License — Copyright (c) 2026 Atharv Dange
- Cairn — https://github.com/thkleinert/cairn — MIT License — Copyright (c) 2026 Thomas Kleinert

The following Crew primitives are local adaptations of published component patterns. They do not fetch third-party data or bundle third-party assets:

- Componentry Flight Status Card — https://componentry.dev/docs/components/flight-status-card — adapted as Plan Lifecycle
- Componentry Wheel Carousel — https://componentry.dev/docs/components/wheel-carousel — adapted as the local plan-time wheel
- Componentry GitHub Calendar — https://componentry.dev/docs/components/github-calendar — adapted as Crew availability from existing votes
- Componentry Layered Stack — https://componentry.dev/docs/components/layered-stack — adapted as the private-memory stack
- Componentry Hover Transition — https://componentry.dev/docs/components/hover-transition — adapted as the explicit Chat-to-Plan handoff
- 21st React Aria Date Picker — https://21st.dev/community/components/explore/react-aria-date-picker — adapted as Crew's semantic date grid

The Linkup application is an independent project. Required license notices are retained for the referenced open-source material.
